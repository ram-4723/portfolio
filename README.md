# Ramachandran Yadav — Portfolio

Static portfolio site for GitHub Pages. The published website uses `index.html` from the repository root and the adjacent image and certificate assets.

## Publish with GitHub Pages

1. Create a **public** repository named `ram-4723.github.io` under the `ram-4723` GitHub account.
2. Add the contents of this folder (`index.html`, `PROFILE.jpeg`, `BYTECAMP.png`, `NPTEL-Certificate.png`, `NPTEL-Certificate.pdf`, `AI-News-Detector.png`, `PCFORGE.png`, `any3d-preview.png`) to the repository root.
3. In the repository, open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Save and wait for GitHub Pages to publish the site at `https://ram-4723.github.io/`.

The portfolio links the email address and profile that Ramachandran provided for public contact.
